Como funciona

ESP8266 + HC-SR04 + MySQL
1. Sensor identifica
O HC-SR04 mede a distância e identifica a presença de um veículo na vaga.
2. ESP8266 processa
O microcontrolador ESP8266 lê o sensor e aciona o LED RGB físico (Verde = Livre, Vermelho = Ocupada, Amarelo = Agendada).
3. Servidor Web & Banco de Dados
O PHP sincroniza em tempo real com o ESP8266 e persiste leituras, veículos e agendamentos no MySQL.
4. Interface interativa
O sistema exibe o mapa, permite reservar com seu veículo cadastrado e reflete instantaneamente no LED.
